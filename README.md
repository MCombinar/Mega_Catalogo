An interactive, single-page digital sales catalog for MEGA's telecommunication services. Designed to be easily shared with potential clients, it showcases residential, mobile, and business plans in a clear and visually appealing format. This project is built entirely within a single HTML file for maximum portability and ease of use.

## 🚀 Características Principales

- **Arquitectura de Archivo Único**: Totalmente contenido en un solo archivo `index.html` para compartir y alojar fácilmente, sin necesidad de un proceso de compilación.
- **Planes Interactivos**: Los usuarios pueden hacer clic en "Ver Detalles" en los planes residenciales para abrir un modal con información de precios completa (tarifas promocionales y estándar para diferentes métodos de pago).
- **Ofertas Especiales Destacadas**: Una sección dedicada resalta las promociones para nuevos clientes que se cambian de compañías competidoras.
- **Diseño Responsivo**: Se adapta perfectamente a computadoras de escritorio, tabletas y dispositivos móviles para una experiencia de usuario óptima.
- **Acordeón de Requisitos**: Una sección limpia y plegable detalla los documentos y pasos necesarios para contratar un servicio.
- **Integración Directa con WhatsApp**: Múltiples botones de "Llamada a la Acción" están preconfigurados con mensajes personalizados para contactar directamente al promotor de ventas.
- **Catálogo Completo**: Cubre Planes Residenciales, Planes Móviles, el paquete premium "Full Connected Home", Soluciones para Negocios y una tabla de comparación con la competencia.

## 🛠️ Tecnologías Utilizadas

Este proyecto aprovecha la simplicidad de las CDNs para ser completamente autocontenido:

- **React 18**: Para construir la interfaz de usuario.
- **ReactDOM 18**: Para renderizar los componentes de React en el DOM.
- **Babel Standalone**: Para la transpilación de JSX directamente en el navegador.
- **Tailwind CSS**: Para un diseño de utilidades rápidas y personalizadas.
- **Font Awesome**: Para la biblioteca de iconos.
- **HTML5 & ES6+ JavaScript**

---

## 📂 Estructura del Proyecto

Toda la lógica de la aplicación (HTML, configuración de CSS y componentes de React/JSX) está intencionalmente consolidada en un único archivo `index.html`. Esta decisión arquitectónica elimina la necesidad de un servidor de desarrollo o un paso de compilación, haciendo que el proyecto sea extremadamente portátil y fácil de desplegar.

## 🚢 Despliegue

Gracias a su naturaleza como un único archivo estático, este proyecto puede ser desplegado en cualquier servicio de alojamiento estático.

### GitHub Pages (Recomendado)

1.  Ve a la configuración de tu repositorio en GitHub (`Settings` > `Pages`).
2.  En la sección "Build and deployment", selecciona `Deploy from a branch`.
3.  Elige la rama `main` y la carpeta `/ (root)`.
4.  Haz clic en `Save`. Tu sitio estará disponible en `https://<tu-usuario>.github.io/<tu-repositorio>/` en unos minutos.
